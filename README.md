# my-assets · 资产账本

自用小程序，计算余额，管理收支。

## 文件说明

| 文件 | 说明 |
|------|------|
| `my_assets_v3.html` | v3 版本（2个Tab：资产概览 + 收支记事） |
| `my_assets_v4.html` | v4 版本（3个Tab：资产概览 + 收支记事 + 收支统计） |
| `启动测试.bat` | Windows 快捷启动脚本 |

## 功能说明

- **「加载测试数据」** — 一键生成近3个月的示例收支记录和预填资产金额
- **「清空所有数据」** — 快速重置数据环境
- 首次打开无数据时自动提示加载示例
