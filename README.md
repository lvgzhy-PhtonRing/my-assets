# my-assets · 资产账本

自用小程序，计算余额，管理收支。

## 文件说明

| 文件 | 说明 |
|------|------|
| `my_assets_v3.html` | v3 版本（2个Tab：资产概览 + 收支记事） |
| `my_assets_v4.html` | v4 正式版（3个Tab：资产概览 + 收支记事 + 收支统计） |
| `my_assets_v4_local.html` | **本地测试版**（基于 v4，增加测试数据加载和清空功能） |
| `启动测试.bat` | Windows 快捷启动脚本 |

## 本地测试

双击打开 `my_assets_v4_local.html` 即可使用（浏览器需联网加载 Tailwind CSS）。

**本地测试版独有功能：**
- 🧪 「加载测试数据」按钮 — 一键生成近3个月的示例收支记录和预填资产金额
- 🗑️ 「清空所有数据」按钮 — 快速重置测试环境
- 首次打开无数据时自动提示加载示例

## 测试指南

1. 打开 `my_assets_v4_local.html`
2. 点击「加载测试数据」体验完整功能
3. 切换底部Tab查看各页面效果
4. 测试快照生成/对比功能
5. 测试导出/导入数据备份
